# FreelancerOS - User Stories

## Authentication

### US-001

As a freelancer,

I want to create an account,

So that I can securely access my workspace.

---

### US-002

As a freelancer,

I want to log in,

So that I can manage my business.

---

## Dashboard

### US-003

As a freelancer,

I want to see a dashboard,

So that I can quickly understand my business status.

---

## Clients

### US-004

As a freelancer,

I want to add new clients,

So that I can manage all my clients in one place.

---

### US-005

As a freelancer,

I want to edit client information,

So that I can keep client records updated.

---

### US-006

As a freelancer,

I want to delete inactive clients,

So that my workspace stays organised.

---

## Projects

### US-007

As a freelancer,

I want to create projects,

So that I can organise my work.

---

### US-008

As a freelancer,

I want to assign projects to clients,

So that I know who each project belongs to.

---

### US-009

As a freelancer,

I want to update project status,

So that I always know project progress.

---

## Tasks

### US-010

As a freelancer,

I want to create daily tasks,

So that I can organise my work efficiently.

---

### US-011

As a freelancer,

I want to mark tasks as completed,

So that I can track my progress.
